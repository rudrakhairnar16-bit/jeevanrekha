# Phase 4 — Jury & Product Polish

## Goal
Make the prototype explain its strongest defensible proof in roughly 90–120 seconds without adding landing-page length or pretending extensions are equally mature.

## Changes
- Reframed the prototype hub around the primary MVP proof: Doctor → Citizen consent → scoped Doctor access/revocation.
- Replaced the broad feature-first hero copy with a minimum-necessary permission story.
- Compressed Guided Jury Demo from seven competing beats to six focused beats.
- First three guided beats are explicitly CORE; emergency and population analytics are labelled EXTENSIONS; security is the trust close.
- Removed Family as a mandatory guided stop. It remains freely explorable, but no longer interrupts the core jury narrative.
- Shortened role descriptions to describe the decision/boundary rather than advertise features.
- Preserved Built / Simulated / Proposed evidence labelling from Phase 2.
- Did not lengthen the cinematic landing or add new product capabilities.

## Recommended jury path
1. Doctor — match + minimum-necessary request.
2. Citizen — WHO / WHAT / WHY / HOW LONG; allow/deny.
3. Doctor — exact granted scope only; expiry/revocation remains visible.
4. Responder — concise emergency extension.
5. Public Health — aggregate extension with coverage/confidence.
6. Security — reviewability + CARE CONTINUES close.

## Validation boundary
This phase changes presentation hierarchy and guided-demo copy/state routing. Full production build, browser timing, axe and E2E execution remain Phase 5 release gates; no unexecuted test is labelled PASS here.
